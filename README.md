One line, one useless superpower: breathing underwater sounds heroic until the fine print says the only water it works on is water already inside you. You cannot drown in water you have drunk, and you cannot use the power anywhere it would matter — the whole joke is the qualifier.

> I can breathe underwater, but only water I've already drunk.

## Run it

```sh
python3 main.py
```

Writes the single line (60 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), exactly the line and nothing else — no trailing newline. Python 3 standard library only, deterministic, no network.
